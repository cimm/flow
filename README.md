# Flow

A native desktop application for GNOME that interfaces with the local [HomeWizard](https://www.homewizard.com/) API to monitor real-time electricity, water, and gas consumption.

```bash
$ nix develop
$ HOMEWIZARD_HOST=<your-p1-ip> ./flow
```
